# Свежие мемы для KotoPotok
#
# Формат одной строки:
#   прямая_ссылка_на_mp4_или_webm | Название | Автор/лицензия
#
# Пример (замени на свою ссылку):
#   https://www.youtube.com/watch?v=9ncW8GFL-gQ
#
# Правила:
# 1. Ссылка должна вести сразу на видеофайл (.mp4 или .webm), а не на страницу сайта.
# 2. Публикуй только то, что имеет лицензию на перепубликацию или разрешение автора.
# 3. Строки, начинающиеся с #, игнорируются.
# 4. Один ролик публикуется один раз — потом бот запомнит его в data/bot.db.
# 5. Если файл пустой, бот продолжает брать котов и мемы из Wikimedia Commons.
